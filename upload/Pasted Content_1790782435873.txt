1. Executive Summary

1.1 Vision Statement

Evolution Idle is a narrative-driven incremental game about a god awakening, growing through observation of life, and ultimately deciding what kind of universe deserves to exist forever. Players guide civilization from single-cell organisms to galactic transcendence across 7 stages and 10 divine layers, balancing active engagement with idle progression.

1.2 Core Pillars

Narrative as Reward - Story is earned through progression, not given freely

Meaningful Choices - Every decision shapes the run and the god's identity

Depth Through Layers - Each layer adds new mechanics without invalidating previous ones

Idle + Active - Both playstyles are equally valid and supported

1.3 Target Audience

Fans of incremental/idle games (Cookie Clicker, Kittens Game, Realm Grinder)

Players who enjoy narrative-driven games with cosmic themes

Completionists who want to unlock everything


2. Core Loop

2.1 Run Structure

Start: Always begins at Cell stage

Progression: Move through 7 stages (Cell → Creature → Tribal → Civilization → Empire → Solar → Galactic)

End: Galactic victory screen + unlock first prestige layer

Meta: Shop upgrades accelerate future runs; automation can eventually make runs fully idle

2.4 Offline Progression

System: Full simulation with banked time cap

Base Bank: 24 hours

Shop Upgrade: Temporal Reserves (adds +24 hours per tier, infinite purchases)

Behavior: On return, game simulates all ticks at max speed compression

Summary: "You were away for X hours" showing resources gained, milestones, auto-resolved events

2.5 Failure States

Each stage has potential failure conditions:

Cell: Resource starvation (ATP/glucose/proteins)

Creature: Population collapse, food/water exhaustion

Tribal: Rebellion, food shortage

Civilization: Civil war, happiness collapse

Empire: Dark Age (regression), logistics failure

Solar: Colony cascade failure

Galactic: Schism, ascension collapse

Failure = Run ends, shows summary screen, player can start new run


3. The 7 Stages

3.1 Cell Stage

Tone: Isolation, wonder, struggle

Duration: 5-60 minutes (active)

Core Mechanics:

ATP-first survival

Organelle purchase unlocks new resources

Radar graph shows emerging lineage

First run includes tutorial

Key Systems:

Manual actions: Absorb Glucose, Scavenge Proteins, Collect Lipids, Extract Elements

Automation: Membrane Pump, Ribosome, Vacuole, Mitochondria

Progression gate: Must build Nucleus and 8+ organelles to evolve

Tutorial: Only on first run, covers ATP, organelles, score target

New Player Experience: Gentle introduction, wonder-focused narrative

3.2 Creature Stage

Duration: 30-90 minutes (active)

Core Mechanics:

Body plan development

Food/water become primary resources

Population management

Knowledge and culture introduced

Lineage Lock System:

Purchases made during stage shift lineage radar

Lineage is locked at stage exit (cannot change after evolution)

First run: lineages appear as "???" until locked

Subsequent runs: revealed lineages show names for easier targeting

Narrative: First body, hunger, thirst, fear, movement, instinct

3.3 Tribal Stage

Duration: 60-120 minutes (active)

Core Mechanics:

Villages and settlement building

Population management becomes meaningful

Resource conversion (wood→lumber, etc.)

Happiness becomes active mechanic

Happiness System:

Affects production (low = debuff, high = buff)

Too low triggers rebellion → potential failure state

Luxury resources improve happiness

Culture works with happiness and population growth

3.4 Civilization Stage

Duration: 120-180 minutes (active)

Core Mechanics:

Cities and urbanization

Production, gold, formal research

Government and law

Formal military

Culture: Not just a resource; required for tech unlocks, affects happiness and population growth

3.5 Empire Stage

Duration: 120-180 minutes (active)

Core Mechanics:

Multiple regions on a single world

Logistics and administration

Rivals become active (background pressure)

Gilded Age possible (big bonuses)

Dark Age possible (regression, failure state if mismanaged)

3.6 Solar Stage

Duration: 3-5 hours (active)

Core Mechanics:

Multiple planets for colonization

Energy, alloys, and data become primary

FTL choice mechanic

FTL System:

Tech tree leads to 3 options that each have their own subtrees

Only one choice can be made in the end, but all subtrees can be completed

Final FTL options: Warp Lensing, Hyperlane Resonance, Wormhole Apertures

Scale Shift: No longer one planet, but many worlds

3.7 Galactic Stage

Duration: 6-24 hours (active)

Core Mechanics:

Interstellar civilization

Megastructures

Multiple ascension paths

4.3 Transcendence Layer

Story: The god steps outside creation, draws power from sacrifice

Unlock: Complete all Divinity foresight nodes + all required route archetypes

Mechanics:

Offerings (sacrifice run output → Divinity)

Rituals (expensive one-time interventions)

Scripts (conditional automated divine behaviors)

Offerings:

Sacrifice excess production, surplus resources, stabilized infrastructure, or population

Tension between mortal progress and divine ascent

Blood Pact = population sacrifice (dark option)

Rituals:

Direct, instant results

Can get tech or buildings the player hasn't unlocked

Expensive but powerful

Examples: stabilize collapsing stage, force open future unlock, resolve pressure spike, short-term surge

Scripts:

Set-and-forget (editable at will)

Conditional divine behaviors

Examples: trigger rite when happiness crashes, convert resource when deficits begin, protect during crisis

Emotional Cost: Sacrifice feels meaningful (player is sacrificing their civilization's lifeblood or population itself)

Persistence: Offerings become permanent meta-source; scripts persist as reusable divine logic after layer mastery

4.4 Genesis Layer

Story: The god stops inheriting universes and begins authoring them

Unlock: Master every ritual category + complete "transcendent run" built around Offerings

Mechanics:

World creation (character creator-style UI) with additional customizations unlocked each run

Cradle Worlds, Prime Conditions, Sacred Geography, Dormant Seeds

EP modifier tradeoff (harder worlds = more points)

World Creation Components:

Cradle World (choose one): oceanic, arid, toxic, glacial, lush, volcanic, subterranean, crystalline, exotic

Prime Conditions (choose one): abundant water, unstable climate, rich minerals, weak gravity, fungal bloom, sparse biosphere

Sacred Geography (shape map): landmarks, dead zones, natural wonders, ruins, rich regions

Dormant Seeds (hidden in world): relics, ancient projects, ruins, mythic conditions that awaken later

World Difficulty & EP Modifier:

Easy worlds: 0.7x EP (lush, abundant water)

Normal worlds: 1.0x EP (balanced choices)

Hard worlds: 1.6x EP (toxic, sparse biosphere)

Maximum extreme: ~2.5x EP

Modifier displayed during world creation

Save Slots: 3 world configurations; shop can expand

World Choice Impact: Can change a run in very intense ways (e.g., building a world with no possibility for agriculture)

Persistence: Full world-authoring suite becomes permanent between runs after layer mastery

Echoes:

Ghost civilizations or divine residues from completed runs

Passive bonuses: science, stability, military, trade, faith, exploration

Forks (simplified - no parallel game):

Borrow strength from future run now

Intense penalties in all future runs until repaid with interest

Can be paid off over multiple runs

Persistence: Echo libraries and selected historical branches remain available forever after layer mastery

6. Narrative System

6.1 Delivery Methods

Dialog Boxes: For major story moments (stage transitions, layer unlocks)

Journal Tab: Complete unlocked story, viewable anytime

Story Popups: First-time events (stage arrivals, first FTL, first miracle)

Environmental: Theme changes, UI elements that reflect narrative state

6.2 Story Structure

Primary Arc: Linear (god awakening → learning → authorship → eternity)

Branching Sub-stories: Based on player choices (alignment tracking)

All Endings: Logged in Journal and Archive, equally valid

6.3 Alignment Tracking

Invisible score (never displayed as a number)

Accumulates from choices the player already makes:

Worship Mode: Fear/Duty → authoritarian; Devotion/Transcendence → benevolent

Heresy Responses: Suppress/Weaponize → tyranny; Absorb/Legalize → mercy

Miracle Usage: Curse Dissent/Apocalypse Rite → dark; Declare Jubilee/Jubilant Peace → benevolent

Offerings: Blood Pact → dark

Surfaces In: Story entries, final narrative, available Eternity endings

Tone: Player should sense their alignment through story beats, not read it off a bar

Run Reset: Only meta upgrades persist

Layer Unlock: Layer progress persists across runs

17. Appendix: Unanswered Mechanical Questions (Resolved)

Q-A1: God Alignment

Answer: Invisible accumulated score. Surfaces in story entries, final narrative, Eternity endings. Never displayed as number. Player senses tone through story beats.

Q-A2: Galactic Endings

Answer: 5 paths × 2 alignment variants = 10 endings. Compassionate vs Tyrannical versions per path. Archetype colors flavor text. All logged equally.

Q-A3: Between-Runs Setup

Answer: Summary → Unlocks → Configuration → Seed Run. Configuration surfaces layer-specific choices (Genesis, Apotheosis, etc.). Quick Restart uses previous config.

Q-A4: Offline Progression

Answer: Full simulation with banked time cap. Base 24 hours, extendable via Temporal Reserves shop upgrade (infinite tiers). No separate time currency.

Q-A5: Forks

Answer: Dropped parallel game. Replaced with ghost projections: player designates decision, watches two simulated trajectories for ~30s, commits to one. Discarded branch gives small passive bonus.

Q-A6: Archive/Timeline

Answer: Prominent Journal sub-tab. Auto-generated entries per run. Pinnable favorites. Archive milestones (25/50/100/200) give permanent bonuses. Timeline tracks milestone moments within runs.

Q-A7: Contracts

Answer: Live in Stage panel under "Wager" header (not Challenge tab). Voluntary self-imposed difficulty. Optional, EP-focused. Cannot stack with active Evolution Challenge.

Q-A8: Rivals

Answer: Background lore before Empire. Mechanical pressure starts at Empire. Primary failure is internal (collapse, rebellion). Rivals create urgency, not hard failure. Galactic exception: rival ascension gives player a narrow catch-up window.

Q-A9: Congress/Institution

Answer: Managed background complexity. Proposals surface in Focus panel as "choice" tier. Pick one, move on. Institution crises are rare and impactful. Lineage laws are most interesting, surfaced clearly.

Q-A10: Threat/Crisis/Scar

Answer: Threats = visible warnings (Focus panel). Threats ignored too long = crisis (urgent). Crisis ignored = run end. Scar Recovery Archive at Galactic transforms scars into positives.

Q-A11: Vassals

Answer: Mid-Empire to Solar mechanic. Rewards diplomatic rival handling. Modest resource trickle + removes rival pressure. No active management required.

Q-A12: Doctrine/Specialization

Answer: Specialization = one choice per run at Creature. Defines clear identity. Lineage doctrines (2 per archetype) = cultural identity. Evolved doctrine = unique story beat.

Q-A13: Challenge Count

Answer: 35 total (5 per stage). Full distribution specified above.

Q-A14: Bad World/Scoring

Answer: Displayed EP modifier during world creation. Easy = 0.7x, Hard = 1.6x, Extreme = 2.5x max.

Q-A15: Achievements

Answer: 200-300 total. Hidden until earned, category progress shown. 0.5-1% bonuses each. 20-30% total at full completion.

Q-A16: Tutorial

Answer: Cell only, first run. Each subsequent stage gets "What's New This Stage" modal (one screen, dismissable). Reset-able in Options.

Q-A17: Mask Change Cost

Answer: 500 Divinity aggregate. Available from Divinity layer panel. Clear warning shows cost and what changes.

Q-A18: Fantasy Mode

Answer: Session-level toggle, unlocked from cosmetics shop after Eternity. Cosmetic text replacement only. No mechanical changes. Journal/Archive preserve mode used during run.

Q-A19: Feedback Form

Answer: Drop in-game form. Use link (Google Form, Itch.io thread) on Eternity completion screen.

Q-A20: Multiple Save Slots

Answer: 3 local slots. Selectable from start screen. Export/Import on selected slot. No cloud sync.

Q-A21: Audio

Answer: None at launch. May add later. Music shifts tone with each stage. Prestige layers get ambient layer. Sound effects for purchases, milestones, events. Full audio settings in Options.

Q-A22: Accessibility

Answer: 4 color blind modes. Font size scaling (3 options). Tooltip text on hover + long-press. Screen reader support post-launch.

Q-A23: Mobile Layout

Answer: Web-first. Mobile-aware CSS (single-column below 768px). Bottom tab bar on mobile. PWA manifest at launch.

Q-A24: Prestige Shop Structure

Answer: Visible tiers that unlock sequentially. Tier 1 (win 1+), Tier 2 (win 3+), Tier 3 (win 5+), Tier 4 (win 10+). Higher tiers visible but locked with label. Search/filter option.
